# Проверка прототипа

Дата: 1 ноября 2026 года. Проверялся локальный проект MyBoxFoxel на вымышленных данных, по адресу `http://127.0.0.1:4173`.

## Автоматические проверки

- `npm run check`: синтаксис семи JavaScript-файлов, язык HTML, существование подключённых локальных ресурсов и импортов.
- `npm test`: 9 тестов успешно. Проверены корректная подпись MAX на синтетических данных, Unicode, подмена пользователя, другой токен бота, просроченные и будущие данные, точная часовая граница, дубли параметров, некорректный JSON, собственная cookie-сессия и выход, отказ запросам с чужим origin и недоступность файлов сервера через HTTP.
- Проверены демонстрационные данные шести недель: суммы по дням и предметам совпадают с итогами, число активных дней соответствует графику.

## Проверка в браузере

- Главный экран, переключение ученика и разные наборы предметов/заданий.
- Решение упражнения: неверный ответ, повторная попытка, верный ответ, обновление счётчика и сохранение результата после перезагрузки.
- Поиск заданий и понятное пустое состояние.
- Смена учебной недели с обновлением графика и показателей.
- Фильтр наград по олимпиадам и фактическое скачивание образца SVG.
- Профиль явно сообщает, что реальный Фоксфорд не подключён.
- Базовый/расширенный сценарии и сброс созданного при тестировании демо-прогресса.
- Модальное окно: переход Shift+Tab остаётся внутри окна, Escape закрывает его и возвращает фокус на кнопку открытия.
- Широкая компоновка при размере окна 1280×900 и мобильная при 390×844. На мобильном главном экране горизонтального переполнения и обрезанных элементов управления не обнаружено. Боковое меню заменяется нижней навигацией.
- В готовой версии после перезагрузки ошибок и предупреждений браузера не обнаружено.

Снимки: [широкий экран](screenshots/desktop-home.jpg), [мобильный экран](screenshots/mobile-home.jpg).

## Что остаётся проверить при подключении

Настоящий бот, его токен, запуск в клиентах MAX, HTTPS-хостинг, авторизация Фоксфорда и реальные учебные API в этом прототипе не подключались. Серверная проверка MAX испытана на синтетических подписанных данных; это не доказательство входа через зарегистрированного бота. Реальную связь с Фоксфордом и права на данные детей нужно реализовать отдельно по [плану интеграции](max-integration.md).
